# 🤖 بوت تيليجرام للتخزين الشخصي

بوت تيليجرام يتيح لك رفع وتخزين أي ملف (صور، فيديوهات، مستندات...)
واسترجاعه لاحقاً باستخدام كود مخصص.

---

## 📁 هيكل المشروع

```
telegram_storage_bot/
├── main.py                 ← نقطة البداية
├── config.py               ← قراءة المتغيرات البيئية
├── database.py             ← كل عمليات قاعدة البيانات
├── supabase_schema.sql     ← سكيما قاعدة البيانات (شغّله مرة واحدة)
├── requirements.txt        ← المكتبات المطلوبة
├── .env.example            ← نموذج ملف الإعدادات
├── handlers/
│   ├── auth.py             ← التسجيل والموافقة على المستخدمين
│   ├── files.py            ← رفع وتنزيل وحذف الملفات
│   └── admin.py            ← أوامر الإدارة
└── middlewares/
    ├── rate_limit.py       ← حماية ضد الإغراق
    └── auth_check.py       ← فلتر التحقق من الهوية
```

## 🚀 خطوات النشر (مجاناً)

### الخطوة 1: إنشاء البوت
1. افتح تيليجرام وابحث عن `@BotFather`
2. اكتب `/newbot` واتبع التعليمات
3. احفظ الـ **Bot Token**

### الخطوة 2: إعداد قاعدة البيانات (Supabase)
1. اذهب إلى [supabase.com](https://supabase.com) وأنشئ حساباً مجانياً
2. أنشئ مشروعاً جديداً
3. اذهب إلى **SQL Editor** والصق محتوى `supabase_schema.sql` وشغّله
4. من **Settings → API** انسخ: `Project URL` و `anon key`

### الخطوة 3: معرفة Telegram ID الخاص بك
- أرسل رسالة لـ `@userinfobot` في تيليجرام
- سيعطيك رقم ID الخاص بك

### الخطوة 4: النشر على Railway (مجاناً)
1. اذهب إلى [railway.app](https://railway.app) وسجّل بحساب GitHub
2. اختر **New Project → Deploy from GitHub Repo**
3. ارفع مجلد المشروع على GitHub أولاً
4. في Railway، أضف المتغيرات البيئية:
   ```
   BOT_TOKEN     = توكن البوت
   SUPABASE_URL  = رابط Supabase
   SUPABASE_KEY  = مفتاح Supabase
   OWNER_ID      = Telegram ID الخاص بك
   ```
5. اضبط **Start Command**: `python main.py`

## 📖 أوامر البوت

### أوامر المستخدمين
| الأمر | الوصف |
|-------|-------|
| `/start` | بدء الاستخدام / عرض التعليمات |
| `/get كود` | استرجاع ملف بالكود |
| `/list` | عرض جميع الملفات |
| `/delete كود` | حذف ملف |

### أوامر الأدمنز فقط
| الأمر | الوصف |
|-------|-------|
| `/users` | عرض جميع المستخدمين |
| `/pending` | عرض الطلبات المعلقة |
| `/addadmin ID` | إضافة أدمن جديد |
| `/removeadmin ID` | إزالة أدمن |
| `/stats` | إحصائيات البوت |
